# K-POP Universe

K-POP의 역사와 특징을 한 페이지로 정리한 웹 제작 실습임.

- 기간: 2026.05.03
- 구분: 개인 웹 제작 실습
- 기술: HTML, CSS, Tailwind CSS

## 만든 내용

- 1990년대부터 2020년대까지 흐름을 구역별로 정리했음.
- 퍼포먼스, 팬덤과 세계적 영향력을 카드 형태로 배치했음.
- 화면 크기에 따라 내용이 맞게 보이도록 구성했음.

## 현재 상태

- 정적 웹 페이지까지 구현한 학습용 결과물임.
- HTML에서 부르는 일부 이미지 파일은 저장소에 남아 있지 않음.

## 실행 방법

- `index.html`을 브라우저에서 열면 됨.
